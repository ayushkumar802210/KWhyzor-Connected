# KWhyzor — Connected Version

This version is Supabase-ready.

1. Create a Supabase project.
2. Run `supabase-schema.sql` in SQL Editor.
3. Configure Email authentication.
4. Put Project URL + browser-safe publishable/anon key into `config.js`.
5. Set `DEMO_MODE: false`.
6. Host the folder.

Real Sign Up, Sign In, password reset, profiles, bills and appliances are connected when Supabase is configured.

Never put service-role, AI, OCR or payment secrets in browser code.
